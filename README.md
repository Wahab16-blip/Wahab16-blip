## ⚽ Featured Project — Football Tactical Analyst

> An AI-powered tactical analysis platform built for football coaches

**Live Demo:** [football-tactical-analyst.streamlit.app](https://football-tactical-analyst-39lecabfsgfatuwaat2cce.streamlit.app)

**What it does:**
- Coaches input their squad with position-specific ability ratings
- AI generates 3 formation recommendations based on real player data
- Live weather API adjusts tactical suggestions for match conditions  
- Real opposition data (last 5 results, goals, form) feeds into analysis
- Full tactical report with formation visualisation on a pitch canvas
- Multi-coach authentication — each coach sees only their own data

**Tech stack:**
`Python` `Anthropic Claude` `RAG Pipeline` `FastAPI` `Streamlit` `SQLite` `bcrypt` `SportAPI` `wttr.in`
